# Contexto General del Sistema y Bitácora de Cambios - Snackver

Este documento centraliza todo el contexto operativo, arquitectura, módulos existentes y el historial de cambios aplicados en la plataforma **Snackver**.

## 1. Contexto del Proyecto

### ¿Qué es Snackver?
**Snackver** (*"Comida entre universitarios - Hecha por estudiantes, para estudiantes"*) es una plataforma de comercio electrónico orientada a la compra y venta de alimentos dentro del campus universitario. Permite que estudiantes emprendedores creen sus tiendas digitales y que otros estudiantes hagan pedidos y coordinen entregas dentro del campus.

### Arquitectura Actual (Pura NoSQL - Unidad 2)
- **Organización Limpia del Proyecto:**
  - `Back-end/`: Contiene toda la lógica del servidor, modelos, controladores y servicios:
    - `Back-end/conexion/`: Singleton de conexión a MongoDB Atlas (`conexion_mongo.php`, `conexion.php`), motor de sincronización diferencial en tiempo real (`sincronizar_tiempo_real.php`) y procesadores de autenticación/recuperación.
    - `Back-end/servicios/`: Servicios en la nube y auditoría (`CloudinaryService.php`, `EmailService.php`, `HistorialService.php`, `NotificacionService.php`).
    - `Back-end/notificaciones/`: Endpoints JSON de tiempo real (`obtener_notificaciones.php`, `marcar_todas_leidas.php`).
    - `Back-end/cliente/`: Módulo del cliente (Dashboard, Tiendas, Carrito, Pedidos, Reseñas, Notificaciones en vivo).
    - `Back-end/vendedor/`: Módulo del vendedor (Dashboard, Catálogo de Platillos, Gestión de Pedidos, Mi Tienda).
    - `Back-end/admin/`: Módulo de administración (Dashboard, Clientes, Vendedores, Categorías, Historial de Auditoría Responsive).
    - `Back-end/js/`: Scripts reactivos de notificaciones y sincronización de pedidos (`notificaciones.js`).
    - `Back-end/vendor/`: Dependencias oficiales instaladas vía Composer.
    - `Back-end/.env`: Credenciales seguras (URI de MongoDB Atlas, API Keys de Cloudinary, SMTP Gmail).
  - `Front-end/`: Vistas de usuario, catálogo público, búsquedas, login, registro, verificación/recuperación OTP en 0 ms, sincronizador diferencial (`Front-end/js/tiempo_real.js`) y estilos CSS/JS.
  - `documentacion/`: Documentación técnica detallada, guía de despliegue cloud, esquema JSON formal, diagramas de BD y archivo histórico SQL.
  - `tools/`: Scripts de diagnóstico, verificación integral, índices compuestos, pruebas unitarias y migración asistida.
- **Base de Datos NoSQL en la Nube:** **MongoDB Atlas** (Cluster M0 / M10 con réplicas, TLS 1.3 y compresión wire `snappy,zlib`).
  - Colecciones (8/8): `usuarios`, `productos`, `pedidos`, `carritos`, `categorias`, `resenas`, `historial_usuarios`, `notificaciones`.
  - Cero consultas SQL o dependencias de MySQL en la aplicación en producción.
- **Servicios Oficiales de GitHub Student Developer Pack:**
  1. **MongoDB Atlas:** Cluster gestionado NoSQL con cifrado en reposo AES-256 y replicación.
  2. **Namecheap:** Nombre de dominio universitario (`snackver.me`) y Certificado SSL (Cifrado en tránsito HTTPS/TLS).
- **Almacenamiento de Imágenes:** **Cloudinary** (almacenamiento en la nube, compresión previa en cliente `<canvas>`, optimización automática `/upload/f_auto,q_auto/` y URLs seguras HTTPS).
- **Tiempo Real Global (0 ms, Cero Recargas):**
  - Sincronización diferencial por hash MD5 (`sincronizar_tiempo_real.php` + `tiempo_real.js`) y sondeo reactivo (`obtener_notificaciones.php` + `notificaciones.js`) que actualizan todas las ventanas del sistema sin recargar la página ni usar `location.reload()`.
- **Seguridad Multicapa:**
  - Hashing seguro de contraseñas con `bcrypt` (erradicación total de contraseñas en texto plano).
  - Autenticación en 2 pasos (2FA): Verificación por código OTP de 6 dígitos vía correo electrónico con Gmail SMTP (SMTPS 465 SSL directo) y PHPMailer, con transición de ventana modal en 0 ms.
  - Gestión de credenciales confidenciales mediante variables de entorno en `Back-end/.env`.
  - Hardening de red con lista de acceso IP (*IP Access List / Firewall*) en MongoDB Atlas.
